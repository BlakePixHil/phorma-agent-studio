One-time setup to run the agent runtime in your own Cloudflare account. You own the worker, the keys and the bill.

  1. Press Set up runtime files below. The worker source ships inside this app - the studio unpacks it and installs its dependencies for you.
  2. Authenticate wrangler with your Cloudflare account: run npx wrangler login once in any terminal. It stores the credentials for your whole machine, so the folder you run it in does not matter.
  3. Press Deploy in the Cloud dialog. Nothing needs hand-editing - if you have several Cloudflare accounts, fill in the Account ID below first.
  4. Set your model keys with the secrets wizard further down (or npx wrangler secret put ANTHROPIC_API_KEY), then paste the deployed Worker URL into the field below.
